GPXファイルをStopsに読み込む方法

ほとんどのハイキング、サイクリング、GPSのAppはGPXで書き出せます。Stopsも同じです。GPXファイルのウェイポイントは、名前、メモ、日付ごとスポットになります。

  • 無料
  • 約2分
  • iPhoneとiPad

必要なもの

  • ファイルAppに保存したGPXファイル（iCloud DriveまたはiPhone上）。

ステップごとに

  1. GPXファイルを「ファイル」に保存

    元のAppやWebサイトからGPXを書き出して、「ファイル」に保存します。Stopsが読み込むのはウェイポイントです。ルートしか含まれていないファイルの場合は、代わりにルートの各地点が取り込まれます。

  2. Stopsで読み込みを開く

    タブバーの右端にある本のボタンからジャーナルを開き、設定の歯車をタップします。読み込む、GPXファイルの順に選び、ファイルを選択します。

  3. 場所を確認して読み込む

    リストにはファイル名が付きます。不要なもののチェックを外して読み込むをタップします。

知っておきたいこと

  • ウェイポイントの種類がStopsのカテゴリ（展望台、キャンプ場、滝など）と一致すると、そのカテゴリになります。Stopsから書き出したGPXは、書き出したときのままの状態で戻ってきます。
  • 記録されたトラックは除外されます。Stopsが残すのは場所であって、道筋ではありません。
  • StopsはGoogle EarthやマイマップのためにKMLを書き出せますが、読み込めるのはGPXだけです。

ほかのガイド

場所を書き出すスポット、リスト、タイムラインを、GPX、KML、CSVでどこへでも。Googleマップの保存済みの場所スターを付けた場所や保存した場所を、Google TakeoutでGoogleマップから移しましょう。AppleマップのガイドAppleマップで作ったガイドを、スポットのリストにしましょう。

Stopsを入手

また訪れたくなる場所を保存。iPhone、iPad、Mac、Apple Watchで。
